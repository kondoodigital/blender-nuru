# Nuru User Documentation

The documentation index moved to the Nuru home page: see the root `README.md` / welcome page. Every page is reachable from the tabs at the top of each document:

| Document | What it covers |
| --- | --- |
| [Nuru Overview](nuru_overview.html) | What Nuru is, supported hardware, workflow, Direct Shadow Catcher, control summary, branch model, and limits. |
| [UI Reference](nuru_ui_reference.html) | Every visible Nuru Quick Settings control plus the Object Visibility Shadow Catcher control. |
| [Shadows And Lights](nuru_shadows_and_lights.html) | Raytrace Shadows, shadow samples, Transparent Shadows, Color Transmission, and Direct Shadow Catcher compositing. |
| [Materials](nuru_materials.html) | Material behavior, reflections, refractions, transparent materials, and practical limits. |
| [Dos And Don'ts](nuru_dos_and_donts.html) | Practical guide: material recipes, the denoiser choice, and the global settings that matter most. |
| [Nuru On Windows](nuru_windows.html) | Windows requirements, installation, SmartScreen notes, GPU denoising, and Cycles CUDA/OptiX support. |
| [Nuru On macOS](nuru_macos.html) | macOS requirements, installation, Developer ID and notarization notes, and Apple Silicon support. |
| [Nuru On Linux](nuru_linux.html) | Linux requirements, installation, and platform notes. |

The current macOS, Windows, and Linux 1.0 packages include Direct Shadow Catcher. The macOS
application is Developer ID signed by Kondoo Digital GmbH and notarized by Apple.
