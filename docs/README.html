Quick Path

  1. Open Render Properties.
  2. Set the engine to Eevee.
  3. Enable Raytracing.
  4. Choose Method: Nuru Raytracing.

Volumetrics, ray-traced GI, shadows, reflections, and refractions all render in the Rendered viewport and final frames.
